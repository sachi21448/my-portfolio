OPTION 1: NETLIFY DROP (RECOMMENDED — ZERO SETUP, LIVE IN 30 SECONDS)
--------------------------------------------------------------------------------
1. Visit https://app.netlify.com/drop
2. Drag and drop your extracted website folder (containing index.html).
3. Netlify will instantly deploy your website and provide a free live URL
   (e.g., https://your-name.netlify.app).
4. Optional: Under "Domain Management", connect your custom domain (e.g. yourname.com)
   with free automatic SSL/HTTPS certificate!

--------------------------------------------------------------------------------
OPTION 2: VERCEL (FASTEST EDGE NETWORK)
--------------------------------------------------------------------------------
1. Visit https://vercel.com and sign in with GitHub or email.
2. Click "Add New..." -> "Project".
3. Upload or push your folder to a GitHub repository, then import into Vercel.
4. Framework Preset: "Other" (Static HTML).
5. Click "Deploy" — your 3D portfolio is now live globally!

--------------------------------------------------------------------------------
OPTION 3: GITHUB PAGES (100% FREE LIFETIME HOSTING)
--------------------------------------------------------------------------------
1. Create a new repository on GitHub named: <your-username>.github.io
2. Upload index.html and portfolio-config.json to the repository.
3. In your repo: Go to "Settings" -> "Pages".
4. Under "Branch", select "main" or "master" and folder "/ (root)". Click Save.
5. In 1-2 minutes, your website will be live at: https://<your-username>.github.io

--------------------------------------------------------------------------------
OPTION 4: CPANEL / APACHE / NGINX / SHARED HOSTING
--------------------------------------------------------------------------------
1. Log into your web hosting cPanel or FTP account (FileZilla / Cyberduck).
2. Navigate to your website document root folder (usually "public_html" or "www").
3. Upload the "index.html" file.
4. Visit your website domain in any browser!

--------------------------------------------------------------------------------
HOW TO RE-EDIT OR RESTORE YOUR CUSTOMIZATION
--------------------------------------------------------------------------------
- Keep your "portfolio-config.json" file safe.
- In the Nova Portfolio Builder, click "Import" in the sidebar and select
  "portfolio-config.json" to restore all your customizations in 1 click!
